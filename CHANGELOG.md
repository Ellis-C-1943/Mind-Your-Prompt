# Changelog

## v0.1.0 - Initial public release

- Added a lightweight local-first prompt manager for AIGC image workflows.
- Added browser-based UI with native HTML, CSS, and JavaScript.
- Added local DATA folder storage for prompt titles, model names, prompt text, input images, and output images.
- Added IndexedDB fallback when opening index.html directly without the local server.
- Added Windows local PowerShell server that listens only on 127.0.0.1.
- Added optional EXE launcher and script-only launcher.
- Added automatic browser opening and automatic server exit after the MYP tab is closed.
- Added theme switching, accent color switching, Chinese/English UI switching, search, filters, image preview, image download, and prompt copy.
- Added safe local image storage with unique filenames and an 80 MB image limit.
- Added README, Chinese README, MIT license, screenshot, favicon, and GitHub-ready project structure.
